# Guia do Condutor — HB20 Comfort 25/26

Guia prático do Hyundai HB20 Comfort 2025/2026: o que cada botão do volante e da central multimídia faz, painel de instrumentos, condução, clima, checklists e cronograma de revisão.

**No ar:** https://cidadaobrasil.github.io/leitoa-assada/

## Como é

Site estático de página única (`index.html`), instalável como PWA (`site.webmanifest`, ícones em `assets/`). Sem build e sem dependências.

Os símbolos reais de cada botão do volante e da central estão em `assets/icons/` (`vd-*` volante direito, `ve-*` volante esquerdo, `c-*` central).

## Como publicar

Editar o `index.html`, commitar e dar push na `main`. O GitHub Pages publica sozinho.

## Atenção ao nome do repositório

O repositório se chama **`leitoa-assada`** e a pasta local também, por herança: antes de 08/08/2026 este endereço hospedava uma receita de leitoa assada, que foi substituída pelo guia do carro.

O nome não corresponde mais ao conteúdo. Se for renomear o repositório no GitHub, lembrar que a URL do Pages muda junto e qualquer link já compartilhado quebra.
